## ১. সাইট কীভাবে ব্যবহার করবেন

সাইটে তিনটা ট্যাব আছে।

| ট্যাব | কী আছে |
|---|---|
| 📘 গাইড | Format, Task 1 (graph, map, process), Task 2 (৫ ধরনের essay), linkers, Letter-এর নিয়ম |
| ✍️ Writing Task | Task 1 ও Task 2 এর প্রশ্ন + sample answer (Task 1 / Task 2 ফিল্টার আছে) |
| 📚 Vocabulary | বইয়ের শব্দ/ফ্রেজ, বাংলা অর্থ ও উদাহরণ বাক্য |

### প্রস্তাবিত পড়ার নিয়ম

1. **গাইড** ট্যাবে কাঠামো পড়ুন।
2. **Writing Task** থেকে একটা প্রশ্ন খুলুন। প্রথমে **১. টিউটোরিয়াল** ট্যাব দেখাবে।
3. উত্তরটা **জোরে জোরে পড়ুন**। একবার পড়া শেষ হলে **✅ আমি একবার জোরে পড়েছি** চাপুন। ৩ বার পড়াই লক্ষ্য। কাউন্টার `0/3` থেকে বাড়বে।
4. এরপর **২. Fill in the gaps** ট্যাবে যান। ফাঁকা ঘরে শব্দ বসান। `Enter` চাপলে পরের ঘরে যাবে।
5. **✔ Check** চাপুন। সঠিক ঘর সবুজ, ভুল ঘর লাল হবে, নিচে স্কোর (%) দেখাবে।
6. আটকে গেলে **👁 উত্তর দেখুন**। নতুন করে শুরু করতে **↺ রিসেট**।
7. ১০০% না হওয়া পর্যন্ত আবার চেষ্টা করুন। হোমপেজে প্রতিটা প্রশ্নের নিচে **পড়া** ও **সেরা স্কোর** দেখা যাবে।

### Gap সম্পর্কে জানার বিষয়

- বড়/ছোট হাতের অক্ষর ধরা হয় না (`Heinous` আর `heinous` একই)।
- যে প্রশ্নে `{{ }}` চিহ্ন দেওয়া নেই, সেখানে সাইট নিজে ৮ বা তার বেশি অক্ষরের শব্দ ফাঁকা করে। ওপরে **কঠিনতা** বেছে নেওয়া যায়: সহজ (কম gap), মাঝারি, কঠিন (বেশি gap)।
- যে প্রশ্নে `{{ }}` দেওয়া আছে (যেমন বই থেকে নেওয়া essay আর Vocabulary), সেখানে শুধু ওই নির্দিষ্ট শব্দ/ফ্রেজই ফাঁকা হয়।
- টিউটোরিয়ালে `{{ }}` এর ভেতরের অংশ **বোল্ড** দেখায়। ওগুলোই মুখস্থ করার মূল শব্দ।

### প্রোগ্রেস সম্পর্কে

পড়ার সংখ্যা ও সেরা স্কোর **ব্রাউজারের localStorage-এ** জমা থাকে। তাই:
- একই ব্রাউজার ও একই ডিভাইসে থাকবে।
- ফোন আর ল্যাপটপে আলাদা আলাদা থাকবে।
- ব্রাউজারের data/cache মুছলে প্রোগ্রেস চলে যাবে (প্রশ্ন-উত্তর যাবে না)।

## 2. কীভাবে আপডেট করবেন

**সব আপডেট শুধু `data.js` ফাইলে।** GitHub-এ ফাইলটা খুলে ✏️ (Edit) চাপুন, বদলান, তারপর **Commit changes** করুন। ১-২ মিনিট পর সাইটে দেখা যাবে। না দেখালে `Ctrl + F5` (ফোনে পেজ রিফ্রেশ) দিন।

`data.js` এ তিনটা তালিকা আছে: `TASKS`, `VOCAB`, `GUIDE`। প্রতিটার শুরুতে `// >>> এখানে ... <<<` লেখা মন্তব্য আছে। **নতুন আইটেম ওই লাইনের ঠিক নিচে পেস্ট করুন।**

### ক) নতুন Writing Task যোগ

`TASKS` এর শুরুতে এটা পেস্ট করুন:

```js
{id:'t2-my-new-topic',
 type:2,
 kind:'Discussion',
 title:'টপিকের নাম',
 prompt:`প্রশ্নটা এখানে।
দ্বিতীয় লাইন।`,
 tips:['ঐচ্ছিক টিপস ১','ঐচ্ছিক টিপস ২'],
 vocab:[['Key phrase','বাংলা অর্থ']],
 answer:`প্রথম অনুচ্ছেদ।

দ্বিতীয় অনুচ্ছেদ (মাঝে একটা ফাঁকা লাইন)।

তৃতীয় অনুচ্ছেদ।`},
```

| ফিল্ড | লাগবে? | মানে |
|---|---|---|
| `id` | ✅ | প্রতিটার **আলাদা** নাম। ইংরেজি, স্পেস ছাড়া। প্রোগ্রেস এই id দিয়ে সেভ হয়, তাই পরে বদলাবেন না |
| `type` | ✅ | `1` = Task 1, `2` = Task 2 (Letter-ও `1`) |
| `title` | ✅ | কার্ডের শিরোনাম |
| `prompt` | ✅ | প্রশ্নের লেখা |
| `answer` | ✅ | Sample answer। অনুচ্ছেদের মাঝে ফাঁকা লাইন দিন |
| `kind` | ঐচ্ছিক | ট্যাগে দেখায়, যেমন `'Agree/Disagree'`, `'Letter (Informal)'` |
| `tips` | ঐচ্ছিক | টিউটোরিয়ালের উপরে সবুজ টিপস বক্স |
| `vocab` | ঐচ্ছিক | টিউটোরিয়ালে শব্দ-অর্থের টেবিল |

**নির্দিষ্ট শব্দ gap করতে** `answer`-এ সেগুলো `{{ }}` এর ভেতরে লিখুন:

```
In recent years, countries have witnessed an {{alarming surge}} in {{heinous}} crimes.
```

কোনো `{{ }}` না দিলে সাইট নিজে gap বানাবে।

### খ) নতুন Vocabulary যোগ

`VOCAB` এর শুরুতে এটা পেস্ট করুন:

```js
{id:'v-my-word',title:'Ubiquitous',topic:'Social Media',words:[
 {w:'Ubiquitous',
  m:'সর্বত্র বিরাজমান',
  s:'rife, pervasive, prevalent',
  ex:[
   "The {{ubiquitous}} influence of social media is evident.",
   "With {{ubiquitous}} access to the internet, remote work is common."
  ]}
]},
```

- `w` = শব্দ/ফ্রেজ, `m` = বাংলা অর্থ, `s` = সমার্থক শব্দ (ঐচ্ছিক), `ex` = উদাহরণ বাক্য।
- `ex`-এর বাক্যে ফাঁকা করতে চাওয়া শব্দ `{{ }}` এ দিন। gap মোডে প্রতিটা বাক্যের আগে বাংলা অর্থ হিন্ট হিসেবে দেখাবে।
- একটা সেটে একাধিক শব্দ দিতে চাইলে `words:[ {…}, {…} ]`।

### গ) নতুন গাইড পেজ যোগ

`GUIDE` এর শুরুতে এটা পেস্ট করুন:

```js
{id:'g-my-guide',title:'গাইডের নাম',topic:'Task 2',sections:[
 ['প্রথম শিরোনাম',['সাধারণ লাইন','- বুলেট লাইন','{{বোল্ড}} করা শব্দ']],
 ['দ্বিতীয় শিরোনাম',['- আরেকটা বুলেট']]
]},
```

- যে লাইন `-` দিয়ে শুরু হয় সেটা বুলেট (•) হবে।
- `{{ }}` এর ভেতরের অংশ বোল্ড হবে।

## 3. ভুল এড়ানোর নিয়ম (খুব জরুরি)

একটা ছোট ভুল হলে **পুরো সাইট ফাঁকা** দেখাতে পারে। কমিট করার আগে এগুলো মিলিয়ে নিন:

1. **প্রতিটা আইটেমের শেষে কমা `,`** দিন (`}` এর পরে)। এটাই সবচেয়ে সাধারণ ভুল।
2. `answer` ও `prompt` ব্যাকটিক (`` ` ``) এর ভেতরে লিখুন। লেখার ভেতরে **ব্যাকটিক** আর **`${`** লেখা যাবে না।
3. সিঙ্গেল কোটের (`'...'`) ভেতরে অ্যাপোস্ট্রফি থাকলে আগে `\` দিন: `'child\'s play'`। ব্যাকটিক বা ডাবল কোটের ভেতরে লাগে না।
4. `id` কখনও দুটো আইটেমে এক রাখবেন না।
5. কোনো `{` বা `[` খুলে বন্ধ করতে ভুলবেন না।

কিছু না দেখালে ব্রাউজারে `F12` চেপে **Console** ট্যাব খুলুন। লাল লাইনে `data.js` এর কোন লাইনে ভুল তা লেখা থাকবে।
